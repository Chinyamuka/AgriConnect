📦 INSTALLATION
================================================================================

# 1. Install Tailwind CSS
npm install -D tailwindcss postcss autoprefixer

# 2. Initialize Tailwind
npx tailwindcss init -p

# 3. Configure tailwind.config.js
# Add your content paths:
content: ["./index.html", "./src/**/*.{js,jsx}"]


📁 FILE STRUCTURE
================================================================================

frontend/
├── tailwind.config.js      # Configuration
├── postcss.config.js       # PostCSS setup
└── src/
    └── index.css           # Tailwind imports + custom styles


⚙️ CONFIGURATION (tailwind.config.js)
================================================================================

/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,jsx,ts,tsx}",
  ],
  theme: {
    extend: {
      colors: {
        // Custom colors
      },
      spacing: {
        // Custom spacing
      },
      fontFamily: {
        // Custom fonts
      },
    },
  },
  plugins: [],
}

📝 BEST PRACTICES
================================================================================

1. USE UTILITY CLASSES
   ✅ <div className="bg-white p-4 rounded-lg shadow">
   ❌ <div style={{ backgroundColor: 'white', padding: '16px' }}>

2. GROUP RELATED CLASSES
   <button className="
     px-4 py-2
     bg-green-600 text-white
     rounded-lg
     hover:bg-green-700
     transition-colors
   ">

3. USE RESPONSIVE PREFIXES
   <div className="text-sm md:text-base lg:text-lg">

4. CUSTOMIZE IN TAILWIND.CONFIG.JS
   // For repeated custom values, add to theme.extend

5. USE @apply FOR REUSABLE COMPONENTS
   .btn-primary {
     @apply px-6 py-3 bg-green-600 text-white rounded-lg hover:bg-green-700 transition;
   }
